# Instagram Clone

An Instagram-inspired social media platform where users can share photos, follow others, like posts, and more. This project replicates key functionalities of Instagram using modern web technologies.

## Features

- **User Authentication**: Sign up, log in, and log out with secure password encryption.
- **User Profiles**: View and edit user profiles with profile pictures and bio.
- **Post Management**:
  - Upload photos with captions.
  - View posts in a feed.
  - Like and comment on posts.
- **Follow System**:
  - Follow and unfollow users.
  - View posts from followed users in the feed.
- **Search**: Discover users and content with a search functionality.
- **Responsive Design**: Fully responsive design for desktop and mobile users.

## Tech Stack

### Frontend
- **HTML5/CSS3**: Structure and styling.
- **JavaScript**: Interactive elements.
- **React** (optional): For building UI components dynamically.

### Backend
- **Node.js**: Server-side runtime.
- **Express.js**: Backend framework for routing and APIs.
- **MongoDB** (or PostgreSQL): Database for storing user data, posts, likes, and comments.
- **Mongoose** (for MongoDB): ORM for database interaction.

### Authentication
- **JWT** (JSON Web Tokens): For secure user authentication.
- **bcrypt**: For password hashing.
